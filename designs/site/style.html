Principles

The rules.

Every page in this style follows these. If a new page breaks one, change the page, not the rule.

  1. Paper and graphite. The page is warm paper and the text is graphite. No pure white, no pure black.
  2. Two colours, two jobs. Ink blue means you can act: links, focus and choices. Highlighter yellow means remember this: key takeaways and the selected bike part. Nothing else is coloured.
  3. Mono for structure, sans for reading. Labels, numbers, navigation and metadata use the monospace. Everything you read uses the text face.
  4. Everything is indexed. Navigation and sections are numbered [01], [02]. Hierarchy uses tree lines (└). Long pages have an “On this page” index with reading progress.
  5. Facts before prose. Every page opens with a grid of fields, such as Level, Evidence and Last checked, like a workshop job card.
  6. Flat and square. 1 px rules, no shadows, corners no rounder than 2 px. Buttons are solid graphite blocks with mono labels.
  7. One progress pattern. Reading progress, the fit check and the bike explode all use the same hatched bar.
  1. Three voices. Condensed headlines announce. A serif carries everything you read. Mono capitals label things: navigation, buttons, bylines and dates.
  2. Track lines open every page. The four lines painted on a velodrome track (a band, then black, red and blue lines) run under each page title, and nowhere else.
  3. Big numbers. Levels, steps and results are set as huge condensed figures, like a lap board. Secondary numbers are outlined.
  4. Ink rules, square corners. Every section starts with a 2 px ink rule and a numbered label. No rounded corners, no shadows.
  5. Colour has a meaning. Blue is something you can click. Red is where you are, or what you’ve selected. That’s all.
  6. Weight shows evidence. Research is a solid block, expert practice is outlined, and a rule of thumb is dashed. The stronger the evidence, the heavier the label.
  7. Slash navigation, wordmark sign-off. The nav reads BikeFitter / Learn / Check your fit / Explore the bike. Every footer ends with the full-width wordmark.
  1. Each tool has its colour. Learn is blue, Check your fit is green and Explore the bike is amber. The colour follows the tool everywhere: nav dot, icon, panel, button and the selected bike part. Pages that aren’t a tool are ink.
  2. Tools hang on pegboard. Previews sit in white windows on tinted, dotted panels, like tools on a workshop pegboard.
  3. Windows show the real thing. Every preview is a small, true version of BikeFitter’s own interface. Never a stock image.
  4. Shapes, not colours, for evidence. ◆ Research, ● Expert practice, ▲ Rule of thumb. The labels still work in black and white, and for colour-blind readers.
  5. Friendly geometry. 14 px cards, 10 px buttons, 8 px chips, 1 px hairlines. Only windows get a shadow.
  6. One icon set. 24 px grid, 1.75 px rounded strokes, drawn for BikeFitter. No emoji.
  7. Plain, left-aligned headings. Sentence case and semibold. Only a page’s opening and its closing panel are centred; lessons stay left, like articles. Anything that takes you somewhere ends with an arrow.

      Avoid

      Don’t.

      • Don’t decorate with colour.Blue and yellow have jobs. If it isn’t a link or a key point, it’s graphite.
      • Don’t centre reading text.Text sits on the left edge of the reading column, like a notebook.
      • Don’t add shadows or gradients.Depth comes from rules and paper tones only.
      • Don’t set paragraphs in mono.Mono is for labels, numbers and structure.
      • Don’t use red or blue as decoration.Blue is clickable, red is selected. Track lines appear once per page.
      • Don’t round corners.Everything is square, like a printed programme.
      • Don’t set headlines in the serif.The serif is for reading; headlines are always condensed.
      • Don’t bury numbers.If a number matters, make it big.
      • Don’t add a fourth colour.Three tools, three colours. Everything else is ink and grey.
      • Don’t use colour for evidence.Evidence labels use shapes.
      • Don’t shadow cards.Only windows float; cards sit flat on the shelf.
      • Don’t use emoji or stock art.Use the icon set and real interface previews.
